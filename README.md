# AI Software Engineer Agent

An AI-powered software engineering assistant for code review
and code analysis.

## Features

- AI-powered Python code analysis
- Code review
- Backend API using FastAPI
- Frontend using React
- OpenAI integration
- Health-check API

## Technologies Used

- Python
- FastAPI
- React
- JavaScript
- OpenAI API
- Vite

## Project Structure

ai-engine/
├── ai_engine/
├── backend/
├── frontend/
├── tools/
└── .gitignore

## How to Run

### Backend

Activate virtual environment and run:

uvicorn backend.main:app --reload

### Frontend

cd frontend
npm install
npm run dev
